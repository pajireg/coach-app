## iOS Guidance

- Use Swift 6 and the existing SwiftUI architecture.
- `AuthStore` is created once in `CoachAppApp` and injected through the environment.
- `APIClient` is created in `RootView` from stored credentials and injected through the environment.
- Use `@Observable` and `@State var viewModel = MyViewModel()` for local view models.
- Do not introduce Combine or MVVM base classes.
- `APIClient` is an `@Observable final class` marked `@unchecked Sendable`.
- Keep snake-case JSON to camelCase Swift through `JSONDecoder.keyDecodingStrategy = .convertFromSnakeCase`.
- `SWIFT_DEFAULT_ACTOR_ISOLATION = MainActor` is intentionally disabled. Do not enable it casually; doing so has caused `Decodable` conformance errors.
- Named colors in `Assets.xcassets` are auto-generated by Xcode. Do not redeclare them in Swift.
- The Xcode project uses `PBXFileSystemSynchronizedRootGroup`; new Swift files under `ios/CoachApp/CoachApp/` are automatically included. Avoid manual `project.pbxproj` edits unless there is a specific need.

## Android Guidance

- Use Kotlin, Jetpack Compose, Hilt, Retrofit, OkHttp, and Kotlin Serialization.
- `CoachApplication` is `@HiltAndroidApp`; `MainActivity` is `@AndroidEntryPoint`.
- `AuthStore` and `ApiService` are singletons provided through `NetworkModule`.
- Consume ViewModel `StateFlow` with `collectAsStateWithLifecycle`.
- `AuthStore.state` drives the signed-in versus signed-out navigation decision.
- `NetworkModule` currently bakes `authStore.baseUrl` into `Retrofit` at construction time. If the user changes base URL, the app must restart or the module must be recreated.
- OkHttp injects `Authorization: Bearer <apiKey>` and signs out on `401`.
- Use `kotlinx.serialization` with `ignoreUnknownKeys = true` and `coerceInputValues = true`.
- Use `@SerialName` for snake-case API fields.
- Use `LocalRcColors.current` or the `rcColors` composable property for app colors. Do not use `MaterialTheme.colorScheme` for app-specific semantic colors.
- Keep type-safe routes with Kotlin Serialization.
- Keep the custom `RcTabBar` for the 5-tab layout.
