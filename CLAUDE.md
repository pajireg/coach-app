## iOS Architecture

**Dependency injection via `@Environment`**: `AuthStore` is created once in `CoachAppApp` and injected with `.environment(authStore)`. `APIClient` is created in `RootView` from the stored credentials and injected the same way.

**State management**: `@Observable` + `@State var viewModel = MyViewModel()`. No Combine, no MVVM base classes.

**Networking**: `APIClient` is `@Observable final class` marked `@unchecked Sendable` (all properties are `let`). Snake-case JSON ↔ camelCase Swift via `JSONDecoder.keyDecodingStrategy = .convertFromSnakeCase`.

**Concurrency rules**: Swift 6 with `SWIFT_APPROACHABLE_CONCURRENCY = YES`. `SWIFT_DEFAULT_ACTOR_ISOLATION = MainActor` is intentionally **disabled** — the project has a background networking class and enabling it causes Decodable conformance errors.

**Color tokens**: Named colors (e.g. `rcTextPrimary`) live in `Assets.xcassets` and are **auto-generated** by Xcode as `extension ShapeStyle where Self == Color`. Do **not** redeclare these in Swift code — causes `invalid redeclaration` build errors.

**File system sync**: The Xcode project uses `PBXFileSystemSynchronizedRootGroup`. New `.swift` files added to `ios/CoachApp/CoachApp/` are automatically included — no `project.pbxproj` edits needed.

## Android Architecture

**DI**: Hilt throughout. `CoachApplication` is `@HiltAndroidApp`; `MainActivity` is `@AndroidEntryPoint`. `AuthStore` and `ApiService` are `@Singleton` provided by `NetworkModule`.

**State management**: `StateFlow` in ViewModels, consumed via `collectAsStateWithLifecycle`. `AuthStore.state: StateFlow<AuthState>` drives the root nav decision (SignedIn vs SignedOut).

**Networking**: Retrofit 2 + OkHttp. `NetworkModule` bakes `authStore.baseUrl` into the `Retrofit` instance at construction — if the user changes the base URL, the app must be restarted or the module must be recreated. The OkHttp interceptor injects `Authorization: Bearer <apiKey>` and calls `authStore.signOut()` on 401. JSON via `kotlinx.serialization` with `ignoreUnknownKeys = true` and `coerceInputValues = true`; use `@SerialName` for snake_case fields.

**Design system**: Colors are in `RcColors` data class (not Material3 tokens). Access via `LocalRcColors.current` or the `rcColors` composable property. Zone colors are in the `ZoneColors` singleton object. Do not use `MaterialTheme.colorScheme` for app-specific semantic colors.

**Navigation**: Type-safe routes with `composable<RouteClass>` (Kotlin Serialization). Two top-level destinations: `OnboardingRoute` and `MainRoute`. The 5-tab layout lives inside `MainScreen` using a custom `RcTabBar` (not `BottomNavigation`).

**Auth storage**: `SecureStorage` wraps `EncryptedSharedPreferences`. Default base URL is `http://10.0.2.2:8000` (Android emulator localhost).

## Backend

- Auth: `Bearer <apiKey>` header only. API key stored in Keychain (iOS) / EncryptedSharedPreferences (Android).
- Base URL: user-configurable at onboarding. Default `http://localhost:8000` (iOS) / `http://10.0.2.2:8000` (Android emulator). For real-device testing use LAN URL from the Obsidian vault `current-state.md`.
- Trends screen intentionally "준비 중" — backend endpoints not yet exposed.
